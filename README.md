# Mosaiko

Progetto web realizzato con Vite + React e Tailwind CSS, versionato su GitHub e deployato su Vercel.

## Sviluppo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- [Vite](https://vite.dev/) + React (JavaScript)
- [Tailwind CSS](https://tailwindcss.com/) v4 (plugin `@tailwindcss/vite`)
